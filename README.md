# Incinerator

A pixel-art music player for Windows set in a morgue. It has an incinerator that burns hotter as you turn the volume up. It plays your Apple Music,
SoundCloud and MP3s, each from its own morgue drawer.

## Install

Download **[Incinerator.Setup.exe](https://github.com/paulem99/Incinerator/releases/latest/download/Incinerator.Setup.exe)** and run it. You don't need admin rights or anything else installed.

Every time you open the app, it checks for a newer version. If there is one, it asks: **UPDATE NOW** or
**NOT NOW**. Nothing downloads until you say yes, and NOT NOW keeps your current version. While an update is
waiting, the gear in the top-left corner shows a drop of blood, and you can install it from settings.

For Apple Music, the app asks for a free one-time castLabs signing step on first launch (Widevine needs it).
MP3s play without it.

## Keys

| Key | Action |
| --- | --- |
| Space | play / pause |
| N / P | next / previous |
| ← → | seek |
| ↑ ↓ | volume |
| 1 / 2 / 3 | open the APPLE / SOUNDCLOUD / MP3S drawer |
| D | open / close the last drawer |
| Ctrl+F | search |
| Esc | close search / settings |
| Ctrl+= / Ctrl+- | window size |
| Ctrl+Shift+A | show the Apple Music window |
| Ctrl+Shift+L | open the log |
