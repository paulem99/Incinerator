# The Incinerator

A pixel-art music player for Windows set in a morgue. It has a rusted steel door intro, a barbed-wire border,
a morgue-drawer song list, and an incinerator that burns hotter as you turn the volume up. It plays your MP3s
and your Apple Music library together in one list, and MP3s get a toe tag.

## Install

Download **The.Incinerator.Setup.exe** from the [latest release](../../releases/latest) and run it. You don't
need admin rights or anything else installed. After that, the app updates itself: new versions download in the
background, and the gear in the top-left corner shows a drop of blood when one is ready to install.

For Apple Music, the app asks for a free one-time castLabs signing step on first launch (Widevine needs it).
MP3s play without it.

## Keys

| Key | Action |
| --- | --- |
| Space | play / pause |
| N / P | next / previous |
| ← → | seek |
| ↑ ↓ | volume |
| D | open / close the drawer |
| Ctrl+F | search |
| Esc | close search / settings |
| Ctrl+= / Ctrl+- | window size |
| Ctrl+Shift+A | show the Apple Music window |
| Ctrl+Shift+L | open the log |
